# Phase 15 visual gate - designer workflow

**Status: PENDING OPERATOR SIGN-OFF**

Open `http://localhost:5173`, choose Designer, and use a build with at least
three elements.

## A. Workspace hierarchy

- [ ] The viewport is visually dominant at 1366x768 and 1920x1080.
- [ ] Scene is the useful permanent left rail; Add opens a temporary palette.
- [ ] Design, Checks and Output never appear as three stacked panels.
- [ ] Build is the only filled primary command.
- [ ] Closing either rail leaves no clipped or overlapping controls.

## B. Design loop

- [ ] Changing a visible Form parameter produces a labelled CAD draft without
      creating a Recent Build entry.
- [ ] The selected element and its controls remain obvious while the draft is
      updating.
- [ ] A full Build replaces the draft badge with authoritative checks and
      enables Output.
- [ ] Checks lead with the outcome and problems; measured rows remain available.

## C. Visual judgement

- [ ] Studio mode shows a neutral ground, useful light/shadow and the 1.7 m
      reference without hiding the sculpture.
- [ ] Technical mode restores the adaptive grid and reads clearly for measure
      and section work.
- [ ] The Add palette shows recognizable real CAD for every focused primitive,
      with no schematic thumbnail claim.
- [ ] Two selected A/B builds orbit together and the changed-values table
      explains their parameter differences without covering either model.

## D. Fit and finish

- [ ] No text clips at 1366x768, 1920x1080, or a 1024 px-wide browser window.
- [ ] Popovers stay inside the viewport and do not cover the primary Build
      command.
- [ ] Studio mode remains responsive on the operator's integrated GPU.
- [ ] Material colors read as identification aids, never photoreal output.

Record PASS/FAIL and notes below. A failure keeps Phase 15 visually open.
